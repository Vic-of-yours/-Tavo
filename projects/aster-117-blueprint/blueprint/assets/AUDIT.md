# 素材分类与去重审计（r002）

## 结论

- 94 个视觉文件：78 SVG、16 栅格；逐文件 SHA-256 均唯一，精确重复为 0。
- 3 个元数据文件：README、catalog、SHA256SUMS；素材树共 97 个源文件。
- 16 个栅格均已解码和尺寸核验，人物/立绘/头像为 0。
- 所有旧物理路径已迁移到用途目录；公开 packageId、itemId、语义键、CSS 变量与 SVG 内部 ID 保持不变。

## 为什么保留 SVG 合集与独立图标

`sprites/icons.svg` 与 60 个独立图标共享几何，`sprites/masks.svg` 与 6 个独立遮罩共享几何；它们不是相同文件或相同 SHA。合集服务一次加载/`<use>`，独立文件服务按需安装和单项资源索引，因此两种交付形态都有独立用途。内部 symbol/mask ID 不缩短。

## 相似场景说明

- `scenes/qa.webp` 是家园场景的内容裁切，用于社交问答卡；用途、尺寸与构图不同。
- `scenes/station.webp` 是世界球局部的内容裁切，用于北站卡；用途、尺寸与构图不同。

这两组属于派生关系，不是字节相同的重复文件。r002 保留它们，并在 catalog 中分别登记用途；若后续改为运行时裁切，必须先补渲染性能与离线降级验收再退役。
